Additional explicit Ji-An2025 mean-forgetting baselines
====================================================

mean_baselines.py adds Q_mean_model and make_mean_models without changing any
original local RL source file. The release review also exposes all three via
make_model, MEAN_MODELS and the CSV CLI; PRIMARY_MODELS remains unchanged.

    from rl_models.mean_baselines import make_mean_models
    models = make_mean_models()

Q_paper_mean_init_half: Eq10 unchosen-only mean forgetting, explicit initial .5.
Q_paper_mean_init_zero: same equation, explicit local-zero initialization sensitivity.
Q_release_mean: released MBf kernel, chosen learning then BOTH-value forgetting,
                initial .5. Its second parameter is a forgetting UPDATE rate.

With c chosen, u unchosen, r reward, alpha learning and beta inverse temperature:

Paper:    Qc' = (1-alpha)*Qc + alpha*r
          Qu' = retention*Qu + (1-retention)*.5
Released: first apply chosen learning, then Q' = (1-forget_rate)*Q + forget_rate*.5
Policy:   logit_right = beta*(QR-QL)

All rates lie in [0,1]; beta is nonnegative. Each model has three free
parameters: alpha, retention/forget_rate, iTemp. There is no history or side bias.

All three expose the existing Takam-style metadata, session_log_likelihood and
forward/variable-output API. They use the same priors/domains and likelihood
helper as the reviewed model module. Fitting was performed by the equivalent
batched kernel in rl_model_comparison.paper_value_models; parity with these
portable scalar classes is tested. These new additions have not been pushed.

Detailed source audit and matched-data results:
results/rl_model_comparison/20261030_refitted_memory_drift_portraits/index.html

Zero-forgetting and drift-to-other remain in drift_models.py. Source aliases
in the inspected PRLCogAgent are MB1 and MB0md; forgetting-to-mean is MBf.
The release review corrects the older, unverified MFdec alias in the docs.
